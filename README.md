# Mobile View Batch Tester 📱⚡
### *High-Performance Responsive Design & Batch URL Mobile Viewport Testing Extension for Google Chrome*

**Mobile View Batch Tester** is a fast, lightweight Chrome Extension (Manifest V3) engineered for frontend developers, QA engineers, SEO specialists, and UI/UX designers to test websites across real mobile screen resolutions, touch environments, and mobile User-Agents.

---

## 🚀 Key Features & SEO Highlights

* **Batch URL Responsive Testing (Up to 50 URLs per batch)**:
  * Enter or paste a list of up to 50 URLs to test entire sitemaps, landing pages, or staging routes in seconds.
* **CDP-Powered Native Mobile Device Emulation**:
  * Emulates precise pixel dimensions, viewport DPR (Device Pixel Ratio), touch event bindings, and mobile rendering engines.
* **Accurate Device Presets**:
  * **Apple iPhone**: iPhone SE (`375 × 667`), iPhone 14 Pro Max (`430 × 932`), iPhone 12 Pro Max (`428 × 926`), iPhone 15/16 Pro (`393 × 852`), iPhone 13/14/15 (`390 × 844`).
  * **Android**: Samsung Galaxy S24 Ultra (`412 × 915`), Google Pixel 8 / 7 (`412 × 892`).
  * **Tablet & Custom**: iPad Mini (`768 × 1024`) or custom Width × Height dimensions.
* **Mobile User-Agent Simulation (Tab-Scoped)**:
  * Spoofs exact Safari / Chrome mobile User-Agents so servers serve mobile-first HTML without affecting your desktop browsing tabs.
* **Interactive Mobile Window Runner & Navigation HUD**:
  * Sequential URL browser in a standalone phone window with keyboard shortcuts (`[` for previous, `]` for next, URL jumper, and 1-click clipboard copy).
* **Pure Black & White Minimalist Design**:
  * High-contrast monochrome theme (`#000000` / `#FFFFFF`) optimized for speed and clarity.

---

## 🎯 Target Keywords & Use Cases
- **Responsive Web Design (RWD) Testing**: Verify breakpoints, fluid grids, and media queries.
- **Mobile SEO & Core Web Vitals Audit**: Check mobile layout shifts (CLS), tap target spacing, font readability, and viewport responsiveness.
- **QA Automation & Batch Verification**: Review staging links, production releases, and multi-page marketing funnels on mobile.
- **Mobile First Indexing Preparation**: Ensure responsive tags `<meta name="viewport">` and mobile content render as intended by search engines.

---

## 🛠️ How to Install & Reload in Google Chrome

1. Open `chrome://extensions` in Google Chrome.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the `/Users/ooo/chrome-tools` directory.
4. Click the **Mobile Tester** icon in your toolbar to begin batch mobile testing!
